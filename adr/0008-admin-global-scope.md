# ADR-0008: Глобальная область доступа администратора

- **Status:** accepted
- **Date:** 2026-08-10

## Context

Спецификации `access-control` и `organization-groups` требуют: администратор
видит все организации и группы, управляет составом групп и назначениями
менеджеров. Возникает вопрос, ограничивать ли администратора собственными
группами (как менеджера) или предоставить ему безусловный доступ.

## Decision

Администратор имеет **безусловную глобальную область видимости**: все
организации и все группы, без привязки к собственным/custom группам.
**Администратор не имеет собственной группы** (`user-<id>-group` создаётся
только менеджерам); при проверке его доступа группы не проверяются.
Администратор
управляет созданием custom-групп, переносом организаций между группами
(`OrganizationGroupMembership`) и назначением групп менеджерам
(`GroupAssignment`). Правило не вводит иерархии per-org ACL для администратора.

## Consequences

- Функции управления группами доступны только администратору; менеджеры их
  не видят.
- Область доступа администратора не требует вычисления членства — проверка
  роли определяет полный доступ, группы не проверяются.
- Если в будущем потребуется делить администрирование, понадобится новая ADR,
  superseding-эта (этот ADR остаётся неизменным, как исторический артефакт).
