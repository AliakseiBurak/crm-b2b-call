# ADR-0003: Администратор и управление менеджерами

- **Status:** accepted
- **Date:** 2026-08-12

## Context

Системой управляют два типа пользователей: администратор и менеджер.
Необходимо определить, кто создаёт пользователей и как администрируются
менеджеры.

## Decision

Пользователь создаётся администратором и получает фиксированную роль
(`admin` или `manager`, см. ADR-0009). Администратор управляет менеджерами:
создаёт пользователей, задаёт роль, создаёт custom-группы и назначает их
менеджерам, переносит организации между группами. При создании менеджера
автоматически создаётся его собственная группа `user-<id>-group` (см.
ADR-0005). Администратор собственной группы не имеет (см. ADR-0008).

## Consequences

- Администратор — единственный инструмент управления пользователями и
  назначениями.
- Менеджер сразу получает зону ответственности (own-группа) без ручной
  настройки.
- Создание пользователя и его группы связаны одной транзакцией, чтобы не
  возникло менеджера без группы.
