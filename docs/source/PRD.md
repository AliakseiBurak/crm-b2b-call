# Product Requirements Document: Symfony Company Search System

## Vision
CRM для B2B‑телемаркетинга и контактного взаимодействия с акцентом на управление контактами, автоматизацию коммуникаций и предложение обучающих программ. Система целенаправленно создана для эффективного ведения переговоров, записи звонков, генерации персонализированных предложений по курсам и полного цикла взаимодействия с клиентами от первого контакта до подтверждения участия в обучении.

## 1. Обзор продукта

### 1.1 Описание
CRM-система для B2B‑телемаркетинга, объединяющая следующие ключевые возможности:

**Управление контактами:**
- Хранение и структурирование данных о контактах компаний
- Группировка контактов по назначению и статусу
- Шаблоны коммуникаций для быстрых ответов

**Телемаркетинговые каналы связи:**
- Планирование и запись контактов с контактами
- Анализ содержания диалогов
- Генерация персонализированных писем на основе результатов контактов

**Обучающие предложения:**
- Автоматическое создание предложений по курсам после контактов
- Расчёт скидок и актуальных цен
- Отслеживание пройденных курсов и сертификатов

**Маркетинговая рассылка:**
- Пакетная отправка email‑рассылок
- Целенаправленная доставка по группам контактов
- Централизованное управление подписками и отписками

**Права доступа:**
- Роли пользователей (администратор, менеджер, оператор)
- Группировка организаций в группы для распределения ответственности между менеджерами
- У каждого менеджера есть собственная группа (own group), куда попадают его организации
- Менеджеру могут быть назначены дополнительные (custom) группы; доступ ко всем назначенным группам — полный
- Администратор управляет составом групп, переносит организации между группами и видит всё

### 1.2 Целевая аудитория
- Специалисты по продажам и маркетингу
- Менеджеры по обучению сотрудников
- Аналитики рынка

| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | Уникальный идентификатор |
| user_id | UUID | Ссылка на менеджера |
| group_id | UUID | Ссылка на группу организации |
| created_at | datetime | Дата назначения |

### 2.12 Членство организации в группе (OrganizationGroupMembership)
| Поле | Тип | Описание |
|------|-----|----------|
| id | UUID | Уникальный идентификатор |
| organization_id | UUID | Ссылка на организацию |
| group_id | UUID | Ссылка на группу |
| added_at | datetime | Дата добавления |

> **Правила доступа:**
> - У каждого менеджера есть собственная группа (**own group**): создаваемые им организации автоматически попадают в неё.
> - Менеджеру могут быть назначены дополнительные группы (**custom**) через `GroupAssignment`; одна и та же группа может быть назначена нескольким менеджерам.
> - Организация может состоять в нескольких группах одновременно (**Many-to-many**) через `OrganizationGroupMembership`; админ добавляет/убирает организацию из групп.
> - Менеджер имеет **полный доступ** ко всем организациям, чей доступ через группы ему назначен (собственная + назначенные), включая контакты, звонки, рассылки.
> - Администратор видит **все** организации и группы, управляет составом групп и назначениями.

## 3. Сервисы архитектуры

### 3.1 Organization Service
- Поиск организаций
- Управление карточками организаций
- Синхронизация из внешних источников

### 3.2 Contact Service
- Управление контактами
- Установление связей с организациями
- Создание шаблонов общения

### 3.3 Course Service
- Управление курсами
- Расчёт цен по курсам
- Управление предложениями

### 3.4 Call Service
- Планирование звонков
- Запись и анализ разговоров
- Генерация писем для рассылки
- Работа с шаблонами коммуникаций

### 3.5 Email Service
- Пакетная рассылка
- Отслеживание статусов
- Обработка отписки

### 3.6 Integration Service
- Подключение к телефонным системам
- Интеграция с API обучающих платформ
- Email-сервисы (SMTP, SendGrid, etc.)

### 3.7 Role Service
- Управление ролями пользователей (администратор, менеджер, оператор)
- Управление group-структурой:
  - Автосоздание **own group** при создании менеджера; организации менеджера попадают туда автоматически
  - Админ создаёт **custom group** и назначает их менеджерам (`GroupAssignment`)
  - Админ добавляет/убирает организацию из групп (`OrganizationGroupMembership`)
- Определение доступа менеджера: организации из его own group + все назначенные группы
- Правила доступа:
  - Менеджер: полный доступ к организациям своих групп (own + assigned)
  - Администратор: видит всё, управляет группами и назначениями
  - Оператор: доступ только через группы, в которые назначен

## 4. API Endpoints

### 4.1 Organizations
```
GET    /api/organizations           - Список организаций
GET    /api/organizations/{id}      - Детали организации
POST   /api/organizations           - Создать организацию
PUT    /api/organizations/{id}      - Обновить
DELETE /api/organizations/{id}      - Удалить
GET    /api/organizations/search    - Поиск по названию/отрасли
```

### 4.2 Contacts
```
GET    /api/contacts                - Список контактов
POST   /api/organizations/{id}/contacts  - Добавить контакт
PUT    /api/contacts/{id}           - Обновить контакт
GET    /api/contacts/groups         - Список групп контактов
POST   /api/contacts/groups         - Создать группу
```

### 4.3 Contacts Templates
```
GET    /api/templates/contacts      - Список шаблонов
POST   /api/templates/contacts      - Создать шаблон
```

### 4.4 Organization Groups
```
GET    /api/groups                  - Список групп (own + custom)
POST   /api/groups                  - Создать custom-группу (admin)
GET    /api/groups/{id}             - Детали группы с организациями
PUT    /api/groups/{id}             - Обновить группу (admin)
DELETE /api/groups/{id}             - Удалить группу (admin)
POST   /api/groups/{id}/organizations      - Добавить организацию в группу (admin)
DELETE /api/groups/{id}/organizations/{organizationId} - Убрать организацию из группы (admin)
POST   /api/users/{id}/groups       - Назначить группу менеджеру (admin)
DELETE /api/users/{id}/groups/{groupId}    - Снять назначение группы (admin)
```

### 4.5 Roles
```
GET    /api/roles                 - Список ролей
POST   /api/roles                  - Создать роль
PUT    /api/roles/{id}              - Обновить роль
DELETE /api/roles/{id}              - Удалить роль
```
