# B2B Call CRM

## Vision

CRM для B2B‑телемаркетинга и контактного взаимодействия с акцентом на
управление контактами, автоматизацию коммуникаций и предложение обучающих
программ. Система целенаправленно создана для эффективного ведения переговоров,
генерации персонализированных предложений по курсам и полного
цикла взаимодействия с клиентами от первого контакта до подтверждения участия в
обучении.

## Mission

Объединить управление контактами, телемаркетинговые каналы связи, обучающие
предложения и маркетинговые рассылки в единой системе, обеспечив
чёткое распределение ответственности между администратором и менеджерами
через группы организаций.

## Goals

- Конверсия «контакт → обучение»: рост на 30% за 6 месяцев.
- Сокращение времени на рутинные операции: на 50% за 3 месяца.
- Ускорение генерации предложений по курсам: на 70% за 2 месяца.
- Внедрение пользователями: ≥ 80% за 4 месяца.
- Нагрузка: 1000+ организаций, 10 000+ контактов.
- Отклик поиска: < 500 мс. Доступность: 99,5%.

## Non-Goals

- AI‑анализ тональности разговоров (v2).

## Planned modules (later)

- Веб‑поиск: поиск сайта организации в Google/других поисковиках и извлечение
  сферы деятельности и контактной информации — отдельный модуль на базе LLM,
  реализуется позже вне текущего скоупа.

## Principles

1. **Документация — источник истины.** Поведение системы описывается в
   OpenSpec: `openspec/project.md` — видение, `openspec/specs/` — возможности.
2. **Модель доступа не упрощается.** Группы `user-<id>-group`/custom,
   many-to-many членство и полный доступ менеджера к организациям своих групп —
   жёсткие правила (`adr/0005–0008`). Не вводить per-org ACL на отдельные
   организации. Администратор не имеет собственной группы, группы для него не
   проверяются.
3. **Язык артефактов.** Русский текст (тело спецификаций и шаги Gherkin),
   английские ключевые слова Gherkin (`Feature`, `Rule`, `Scenario`,
   `Given/When/Then`).
4. **Traceability.** Каждая спецификация ссылается на ADR и перекрёстно на
   связанные возможности; требований вне OpenSpec не существует.

## Capabilities

| Возможность | Суть |
|---|---|
| `organizations` | Карточки организаций, поиск, синхронизация из внешних источников |
| `contacts` | Единая сущность контакта (тип, контактное лицо, заметки), привязка к организации, CRUD |
| `communication-templates` | Шаблоны писем с токенами и встроенными курсами |
| `courses` | Каталог курсов, расчёт цен, предложения, описания и PDF для писем |
| `calls` | Планирование, обзвон по группам, результат (рассылка/сделка/будущий звонок) |
| `campaigns` | Рассылки (из обзвона/standalone), шаблон с токенами, статусы писем и отписки |
| `organization-groups` | Группы организаций, членство, назначения менеджерам |
| `access-control` | Роли (admin/manager) и правила доступа |

## Technology Stack

Symfony 6.x, PHP 8.2+, Doctrine ORM, Twig, Webpack Encore, MySQL, OAuth2/JWT.
Отправка писем — SMTP via Symfony Mailer (ADR-0010).

## Development Roadmap

1. **Инфраструктура (ADR-0000)** — docker compose, пустой Symfony, начальные
   миграции, фейковые данные для звонков.
2. **Ядро: организации и контакты** — сущности, модель доступа (группы,
   назначения), базовые эндпоинты. Дизайн: `openspec/design/`.
3. **Пользовательский интерфейс** — карточки организаций и контактов, поиск,
   управление группами для администратора.
4. **Обзвон и рассылки** — сущность `Call`, сеанс обзвона, запуск рассылки с
   отслеживанием статусов писем.
