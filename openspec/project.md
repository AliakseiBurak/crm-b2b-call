# B2B Call CRM

## Vision

CRM для B2B‑телемаркетинга и контактного взаимодействия с акцентом на
управление контактами, автоматизацию коммуникаций и предложение обучающих
программ. Система целенаправленно создана для эффективного ведения переговоров,
записи звонков, генерации персонализированных предложений по курсам и полного
цикла взаимодействия с клиентами от первого контакта до подтверждения участия в
обучении.

## Mission

Объединить управление контактами, телемаркетинговые каналы связи, обучающие
предложения и маркетинговые рассылки в единой системе на Symfony, обеспечив
чёткое распределение ответственности между администратором и менеджерами
через группы организаций.

## Goals

- Конверсия «контакт → обучение»: рост на 30% за 6 месяцев.
- Сокращение времени на рутинные операции: на 50% за 3 месяца.
- Ускорение генерации предложений по курсам: на 70% за 2 месяца.
- Внедрение пользователями: ≥ 80% за 4 месяца.
- Нагрузка: 1000+ организаций, 10 000+ контактов.
- Отклик поиска: < 500 мс. Доступность: 99,5%.

## Non-Goals

- Нативное мобильное приложение (v2).
- AI‑анализ тональности разговоров (v2).
- Elasticsearch помимо базового поиска (v2).

## Principles

1. **Документация — источник истины.** Поведение системы описывается в
   OpenSpec: `openspec/project.md` — видение, `openspec/specs/` — возможности.
   OpenSpec — единственный источник истины (ADR-0006); исходный PRD удалён.
2. **Модель доступа не упрощается.** Own/custom группы, many-to-many членство и
   полный доступ менеджера к организациям своих групп — жёсткие правила
   (`adr/0001–0004`). Не вводить per-org ACL на отдельные организации.
3. **Язык артефактов.** Русский текст (тело спецификаций и шаги Gherkin),
   английские ключевые слова Gherkin (`Feature`, `Rule`, `Scenario`,
   `Given/When/Then`).
4. **Traceability.** Каждая спецификация ссылается на ADR и перекрёстно на
   связанные возможности; требований вне OpenSpec не существует (ADR-0006).

## Capabilities

| Возможность | Суть |
|---|---|
| `organizations` | Карточки организаций, поиск, синхронизация из внешних источников |
| `contacts` | Контакты внутри организаций, связи |
| `contact-groups` | Группировка контактов по назначению и статусу |
| `communication-templates` | Шаблоны коммуникаций для быстрых ответов и писем |
| `courses` | Каталог курсов, расчёт цен, предложения, пройденные курсы |
| `calls` | Планирование, запись и анализ звонков, генерация писем |
| `email-campaigns` | Пакетные рассылки, статусы, отписки |
| `organization-groups` | Own/custom группы, членство организаций, назначения менеджерам |
| `access-control` | Роли (admin/manager) и правила доступа |
| `integrations` | Телефония, обучающие платформы, email-провайдеры, хранение записей |

## Technology Stack

Symfony 6.x, PHP 8.2+, Doctrine ORM, Twig, Webpack Encore, Redis,
RabbitMQ/Symfony Messenger, PostgreSQL/MySQL, Elasticsearch, MinIO/S3,
OAuth2/JWT.
