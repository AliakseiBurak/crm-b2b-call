## Why

Архивация рассылок сейчас — это смена статуса через выпадающий список в форме редактирования. После архивации адресаты остаются в `campaign_recipients`, раздувая таблицу. Нужен механизм, который перемещает адресатов в отдельную архивную таблицу и делает архивацию необратимой.

## What Changes

- **Кнопка «Архивировать»** на странице редактирования рассылки (видна для всех статусов кроме `archived`)
- **Страница предупреждения** для запущенных рассылок: «Сначала остановите рассылку»
- **Страница подтверждения** для незапущенных рассылок: «Операция может занять время; адресаты будут перемещены в архив»
- **Архивная таблица** `campaign_recipient_archive` — зеркало `campaign_recipient` без полей `retry_count`, `retry_at`, `tracking_token`, `error_message`
- **Транзакционная архивация**: `status = 'archived'`, `archived_at = NOW()`, `INSERT INTO ... SELECT`, `DELETE FROM campaign_recipients`
- **BREAKING**: `status` **не редактируется** через выпадающий список в форме; переходы статусов — через кнопки (Запустить/Остановить/Архивировать)
- Поле `archived_at` добавляется в таблицу `campaign`
- Страница карточки рассылки читает адресатов из архивной таблицы для архивных рассылок
- Клонирование архивной рассылки читает адресатов из архивной таблицы
- Удаление архивной рассылки каскадно удаляет строки из архивной таблицы

## Capabilities

### New Capabilities

- `campaigns/archive`: Архивация рассылки — кнопка, страницы предупреждения/подтверждения, транзакционное перемещение адресатов в `campaign_recipient_archive`, поле `archived_at` на Campaign

### Modified Capabilities

- `campaigns`: Статус не редактируется через форму; кнопка «Архивировать» на странице редактирования; карточка и клонирование читают адресатов из архивной таблицы для архивных рассылок

## Impact

- `Campaign` entity: новое поле `archived_at` (datetime, nullable)
- `CampaignController`: новый маршрут архивации + страницы предупреждения/подтверждения
- `campaign/form.html.twig`: убрать выпадающий список статуса, добавить кнопку «Архивировать»
- `campaign/show.html.twig`: читать адресатов из архивной таблицы для архивных рассылок
- `Campaign::cloneFrom()`: читать из архивной таблицы если исходная рассылка архивная
- Миграция: создание `campaign_recipient_archive`, добавление `archived_at` в `campaign`
- Удаление рассылки: каскадное удаление из архивной таблицы (FK `ON DELETE CASCADE`)
