## Why

Текущая модель результата звонка (ADR-0004) — комбинация независимых полей
(`is_deal`, `campaign_id`, `next_call_id`) — не соответствует бизнес-процессу: менеджер
фиксирует ровно один из шести типов результата. Комбинация полей не позволяет однозначно
определить исход и создаёт несогласованные состояния. Кроме того, при результате
«рассылка»/«отказ-рассылка» нужно указать кампанию (через связанную `Campaign`).

Изменение зависит от `campaign-entity` (внешний ключ `campaign_id` на `CallResult`) и
реализуется вторым.

## What Changes

- **BREAKING**: Сущность `Call` теряет поля `is_deal`, `campaign_id`, `next_call_id`;
  вместо них — опциональная ссылка `result_id` на новую сущность `CallResult`
- Новая сущность `CallResult` с enum-типом результата и типовыми полями (`campaign_id`, `next_call_id`)
- Формы звонка с динамическими полями: тип результата — выпадающий список; дополнительные
  поля появляются в зависимости от типа (кампания — из `campaign-entity`)
- Валидация: `campaign` обязателен для `mailing`/`refusal_mailing`; `next_call` для `new_call`/`no_answer_new_call`
- Проверка области доступа через организацию звонка (`adr/0007`)
- Авто-запуск: при создании `CallResult` типа `mailing`/`refusal_mailing`, если `Campaign.autoLaunch` — проставить `launchedAt` (хук, контракт с изменением `campaign-entity`)
- Пересоздание БД с фикстурами результатов

## Capabilities

### New Capabilities
- `calls/results`: Типы результатов звонка (enum), сущность CallResult, привязка к звонку, динамические поля в форме

### Modified Capabilities
- `calls`: Модель результата — вместо комбинации полей один `result_id`; опциональный результат

## Impact

- **Сущности Doctrine**: новая `CallResult`; изменена `Call` (удалены is_deal/campaign_id/next_call_id, добавлен result_id)
- **Миграция БД**: пересоздание с фикстурами результатов
- **Контроллеры**: `CallController` — формы с динамическими полями результата
- **Шаблоны/JS**: динамические поля, AJAX-загрузка кампаний
- **Дашборд**: отображение результата звонка
- **Зависимости**: `campaign-entity` (готовая сущность Campaign, FK + auto_launch)
