## Purpose

Типы результатов звонка: единый enum-тип определяет, какой исход зафиксирован по итогам
звонка, а связанная сущность `CallResult` хранит типовые поля (ссылка на кампанию или
следующий звонок).

## ADDED Requirements

### Requirement: Enum типа результата звонка
The system SHALL define a fixed set of call result types: `new_call` (новый звонок), `no_answer_new_call` (нет ответа — новый звонок), `refusal` (отказ), `refusal_mailing` (отказ-рассылка), `mailing` (рассылка), `dealing` (сделка).

#### Scenario: Все типы результатов доступны в выпадающем списке
- **WHEN** менеджер открывает форму фиксации результата звонка
- **THEN** выпадающий список содержит все шесть типов результатов
- **AND** каждому типу соответствует отображаемое название на русском языке

#### Scenario: Значение по умолчанию отсутствует
- **WHEN** менеджер открывает форму нового звонка
- **THEN** тип результата не выбран (результат опционален)

### Requirement: Сущность CallResult
The system SHALL store a call result record with a type, optional campaign reference, optional next call reference, notes, and timestamps.

#### Scenario: Результат типа «рассылка» с кампанией
- **WHEN** менеджер фиксирует результат «рассылка» для звонка по организации «ООО Ромашка»
- **AND** выбирает кампанию «Новые курсы»
- **AND** сохраняет результат
- **THEN** создаётся запись `CallResult` с типом `mailing` и ссылкой на кампанию «Новые курсы»
- **AND** звонок организации «ООО Ромашка» получает ссылку на эту запись результата

#### Scenario: Результат типа «новый звонок» с датой
- **WHEN** менеджер фиксирует результат «новый звонок» для звонка по организации «ООО Ромашка»
- **AND** указывает дату следующего звонка «завтра»
- **AND** сохраняет результат
- **THEN** создаётся запись `CallResult` с типом `new_call` и ссылкой на новый звонок с датой «завтра»
- **AND** организация «ООО Ромашка» попадает в планирование

#### Scenario: Результат типа «отказ» без дополнительных полей
- **WHEN** менеджер фиксирует результат «отказ» для звонка по организации «ООО Ромашка»
- **AND** сохраняет результат
- **THEN** создаётся запись `CallResult` с типом `refusal` без ссылок на кампанию или следующий звонок

#### Scenario: Результат типа «сделка» без дополнительных полей
- **WHEN** менеджер фиксирует результат «сделка» для звонка по организации «ООО Ромашка»
- **AND** сохраняет результат
- **THEN** создаётся запись `CallResult` с типом `dealing`

#### Scenario: Заметка к результату
- **WHEN** менеджер фиксирует результат «отказ» для звонка по организации «ООО Ромашка»
- **AND** вводит заметку «Клиент не заинтересован»
- **AND** сохраняет результат
- **THEN** запись `CallResult` содержит заметку «Клиент не заинтересован»

### Requirement: Опциональность результата звонка
The call result SHALL be optional; a call MAY exist with only the fact of the call (who and when) and no result.

#### Scenario: Звонок без результата
- **WHEN** менеджер завершает звонок по организации «ООО Ромашка»
- **AND** не выбирает тип результата
- **THEN** звонок сохраняется с пустым result_id
- **AND** фиксируется только факт звонка (кто и когда)

### Requirement: Связь типа результата с полями
Each result type SHALL have a defined set of associated fields: `mailing` and `refusal_mailing` require a campaign reference; `new_call` and `no_answer_new_call` require a next call reference; `refusal` and `dealing` have no additional fields.

#### Scenario: Тип «рассылка» требует выбор кампании
- **WHEN** менеджер выбирает тип результата «рассылка»
- **THEN** в форме отображается обязательное поле выбора кампании

#### Scenario: Тип «нет ответа — новый звонок» требует даты
- **WHEN** менеджер выбирает тип результата «нет ответа — новый звонок»
- **THEN** в форме отображается обязательное поле даты следующего звонка

#### Scenario: Тип «отказ» не показывает дополнительных полей
- **WHEN** менеджер выбирает тип результата «отказ»
- **THEN** в форме отображается только поле заметки

#### Scenario: Тип «сделка» не показывает дополнительных полей
- **WHEN** менеджер выбирает тип результата «сделка»
- **THEN** в форме отображается только поле заметки

### Requirement: Динамические поля формы результата
The system SHALL show additional form fields dynamically based on the selected result type without page reload.

#### Scenario: Переключение типа результата обновляет форму
- **WHEN** менеджер выбирает тип «рассылка» в форме результата
- **THEN** появляется поле выбора кампании
- **AND** когда менеджер переключает тип на «отказ»
- **THEN** поле выбора кампании скрывается

### Requirement: Доступ к результатам звонка ограничен областью доступа
The system SHALL allow a manager to view and edit call results only for calls within their access scope (`adr/0007`).

#### Scenario: Менеджер фиксирует результат звонка в своей области доступа
- **WHEN** звонок по организации «ООО Ромашка» доступен менеджеру
- **AND** менеджер фиксирует результат «сделка»
- **THEN** результат сохраняется успешно

#### Scenario: Менеджер не может зафиксировать результат недоступного звонка
- **WHEN** звонок по организации «ООО Конкурент» отсутствует в области доступа менеджера
- **AND** менеджер пытается зафиксировать результат этого звонка
- **THEN** система отклоняет запрос с ошибкой 403
