## Context

Текущее состояние: на дашборде `/dashboard` отображается таблица организаций с кнопками-заглушками, ведущими на несуществующие маршруты (404). Сущности `Organization` и `Contact` уже реализованы с полной доменной моделью. Доступ определяется моделью ADR-0005–0008: менеджер видит организации своих групп, администратор — все.

Ограничения:
- Дизайн-система: поля с оранжевым подчёркиванием, кнопки-пилюли, без теней
- Доступ: проверка области доступа перед каждой операцией
- Валидация: обязательные поля name, industry
- Модальные окна: для быстрых правок без перезагрузки страницы

## Goals / Non-Goals

**Goals:**
- CRUD-операции с организациями (создание, редактирование, удаление)
- Страницы форм и модальные окна
- Валидация полей с сообщениями на русском
- Проверка области доступа (менеджер/администратор)
- Соответствие дизайн-системе

**Non-Goals:**
- CRUD для контактов (отдельный change)
- Пагинация и поиск организаций (уже реализовано)
- Импорт/экспорт организаций
- Групповое удаление

## Decisions

### 1. Raw Twig формы + Symfony Validator

**Решение**: Использовать существующий компонент `form_field.html.twig` для рендеринга полей и Symfony Validator для валидации.

### 2. Vanilla JavaScript для модальных окон

**Решение**: Реализовать модальные окна на чистом JavaScript, как существующий `dashboard-search.js`.

### 3. OrganizationController с проверкой доступа

**Решение**: Один контроллер с действиями new, create, edit, update, delete. Проверка доступа через `OrganizationRepository::findAccessibleIds()`.

### 4. Каскадное удаление через Doctrine

**Решение**: Использовать `onDelete: 'CASCADE'` в Doctrine mapping для контактов организации.

## Risks / Trade-offs

- **Модальные окна без AJAX**: Данные формы загружаются в HTML страницы, что увеличивает размер. Mitigation: использовать делегирование событий и загружать данные только при открытии.
- **Валидация на клиенте**: Отсутствует в модальных окнах. Mitigation: серверная валидация через AJAX, показ ошибок в модальном окне.
- **Удаление без undo**: После подтверждения удаление необратимо. Mitigation: модальное окно подтверждения с предупреждением о каскадном удалении.
