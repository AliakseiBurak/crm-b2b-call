## Why

На панели `/dashboard` отображаются организации с кнопками-заглушками «Изменить», «Создать организацию» и «Создать контакт», которые ведут на несуществующие маршруты (404). Менеджеры и администраторы должны иметь возможность создавать, редактировать и удалять организации через формы, соответствующие дизайн-системе (поля с оранжевым подчёркиванием, кнопки-пилюли, модальные окна для быстрых правок).

## What Changes

- **OrganizationController**: CRUD-контроллер с действиями create, edit, delete для организаций.
- **Страницы форм**: отдельные страницы `/organizations/new` и `/organizations/{id}/edit` с формами создания/редактирования.
- **Модальные окна**: компонент модального окна для быстрого редактирования организации прямо из таблицы на дашборде.
- **Валидация**: Symfony Validator для проверки полей (name, industry) с сообщениями об ошибках на русском языке.
- **Доступ**: проверка области доступа (ADR-0005–0008): менеджер работает только с организациями своих групп, администратор — со всеми.
- **Удаление**: подтверждение удаления организации с каскадным удалением контактов (ON DELETE CASCADE в БД).

## Capabilities

### New Capabilities

- `organizations/crud`: CRUD-операции с организациями (создание, редактирование, удаление), формы, валидация, модальные окна, проверка доступа.

### Modified Capabilities

(нет изменений требований в существующих спеках — только реализация CRUD)

## Impact

- **Код**: новый `OrganizationController`, шаблоны форм, JavaScript для модальных окон, маршруты.
- **Зависимости**: добавление `symfony/validator` в `composer.json`.
- **Дашборд**: обновление кнопок «Изменить» в таблице организаций для открытия модальных окон вместо перехода на несуществующие страницы.
- **Безопасность**: проверка области доступа перед каждой операцией CRUD.
- **Дизайн**: формы соответствуют дизайн-системе (поля с нижним подчёркиванием, кнопки-пилюли, модальные окна без теней).
