## Why

На панели `/dashboard` показана только агрегированная статистика звонков, а рабочий инструмент не даёт перейти к самим объектам работы: списку организаций и их контактов. Менеджер и администратор должны видеть организации своей области доступа с датами звоноков и контактами, чтобы планировать обзвон — без CRUD-форм, только просмотр.

## What Changes

- **Секция «Организации» на дашборде**: ниже блоков статистики отображается таблица организаций с колонками «Название», «Сфера деятельности», «Последний звонок», «Следующий звонок» (зебра, стили таблицы по спец. `web-interface`).
- **Аккордеон контактов**: по клику на строку организации раскрывается список её контактов карточками (стили «Контактных карточек» по спец. `web-interface`: имя, телефон `tel:`, вторичные данные). Кнопки «Позвонить» нет: нажатие на номер открывает системный звонильщик, нажатие на email открывает почтовый клиент; карточки получают кнопки «Изменить»-заглушки (см. ниже).
- **Звонки организации**: в раскрытии организации показывается заметка последнего звонка (`Call.notes`, последний по времени) и раскрывающийся список «Все звонки» — все звонки организации с датой каждого, с заметкой и контактом, если они есть. Заметок организации в доменной модели нет (`Organization.notes` отсутствует) — в этом change они не добавляются.
- **Кнопки действий (заглушки)**: кнопка «Изменить» в строке организации, кнопка «Добавить звонок» в раскрытой секции, кнопка «Изменить» в каждой строке списка «Все звонки», кнопка «Добавить контакт» в секции контактов и кнопка «Изменить» на карточке контакта. Кнопки ведут на страницы редактирования, которые **пока не существуют** (маршруты возвращают 404, как у текущих кнопок «Создать организацию»/«Создать контакт») — формы реализуются отдельным CRUD-изменением.
- **Поиск**: текстовое поле над таблицей фильтрует организации по названию и по контактам (имя/телефон/email).
- **Сортировка**: по названию (А–Я), сфере деятельности (А–Я), последнему звоноку (свежий сверху) и следующему звоноку (ближайший сверху) — переключение по клику на заголовок таблицы.
- **Область доступа**: администратор видит все организации, менеджер — только организации своей области доступа (`user-<id>-group` + назначенные группы, ADR-0007); даты звоноков берутся из реальных данных `Call` (`made_at`/`scheduled_at`).
- Без форм создания/редактирования: кнопки «Создать организацию»/«Создать контакт» и новые кнопки действий ведут на несуществующие маршруты (404-заглушки); формы реализуются отдельным CRUD-изменением.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `dashboard`: панель получает список организаций области доступа с контактами, поиском и сортировкой; требования статистики не меняются.
- `web-interface`: из дизайн-системы удаляется кнопка «Позвонить» на карточках контактов — звонок по клику на номер (`tel:`), почтовый клиент по клику на email (`mailto:`).

## Impact

- **Код**: `HomeController` (рендер таблицы с данными), `OrganizationRepository`/`CallRepository` (запрос организаций с датами звоноков и фильтром по области доступа), `ContactRepository` (контакты выбранной организации), шаблоны `templates/home/dashboard.html.twig` (таблица/аккордеон, может дополнена отдельным частичным), SCSS (таблица и карточки контактов — стили уже зафиксированы в `web-interface`, нужна только привязка страниц), e2e-тесты.
- **Спеки**: дельта `dashboard` (ADDED «Таблица организаций на панели», «Контакты организации на панели», «Поиск», «Сортировка», «Область доступа списка»).
- **Домен**: сущности `Organization`, `Contact`, `Call` и модель доступа (ADR-0005–0008) не меняются — только агрегация и представление существующих данных.
