## 2. Сохранение результата в CallController

- [ ] 2.1 Принимать действия результата только если заполнены `madeAt` и `madeBy`; иначе 422 без побочных эффектов
- [ ] 2.2 Пустая дата следующего звонка — не создавать Call; дата в прошлом — 422 «Дата следующего звонка должна быть в будущем»; будущая дата — создать Call и записать в `next_call_id` только если связанного следующего звонка ещё нет; если `next_call_id` уже есть — не создавать второй и не менять связанный звонок из этой формы
- [ ] 2.3 Выбор кампании `ready`/`launched`: создать `CampaignRecipient` или заменить существующего (включая тот же контакт); контакт по умолчанию — контакт звонка, пусто = вся организация; пустое поле кампании — не менять адресатов
- [ ] 2.4 При замене и непустом `Campaign.launchedAt` увеличить `replacementCount` и показать flash о повторной отправке; без `launchedAt` — замена без счётчика и без flash о resend
- [ ] 2.5 Отказ: удалить `CampaignRecipient` выбранной кампании для организации звонка
- [ ] 2.6 Отказ и письмо одной кампании — одна замена адресата (mailing upsert); разные кампании — удалить отказ и upsert письма
- [ ] 2.7 После 422 восстановить введённые поля результата (кампания, контакт, дата следующего звонка, отказ, чекбоксы)
- [ ] 2.8 Проверка области доступа через организацию звонка (403)

## 6. Ручная проверка

- [ ] 6.1 Проведённый звонок: письмо в `ready` создаёт адресата; повторное сохранение без выбора кампании не дублирует
- [ ] 6.2 Запущенная кампания, тот же контакт с формы звонка и со страницы адресатов — замена, счётчик +1, flash, worker видит `pending`
- [ ] 6.3 Отказ A + письмо B в одном сохранении; отказ и письмо одной кампании — замена/повторная отправка, не удаление
- [ ] 6.4 Следующий звонок создаётся один раз; повторно дата на исходной форме недоступна; правки и удаление будущего звонка — через его строку на панели; после удаления будущего `next_call_id` исходного пуст и поле даты снова видно; удаление исходного звонка оставляет адресата и следующий звонок
- [ ] 6.5 «Нет ответа» или сделка вместе с рассылкой; действия без `madeAt`/`madeBy` — 422; дата следующего звонка в прошлом — 422 с восстановлением рассылки и даты; 403 вне области
