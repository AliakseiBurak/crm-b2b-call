## 6. Ручная проверка

- [x] 6.1 Проведённый звонок: письмо в `ready` создаёт адресата; повторное сохранение без выбора кампании не дублирует
- [x] 6.2 Запущенная кампания, тот же контакт с формы звонка и со страницы адресатов — замена, счётчик +1, flash, worker видит `pending`
- [x] 6.3 Черновик и failed доступны в списке рассылки; archived отсутствует
- [x] 6.4 Следующий звонок создаётся один раз; повторно дата на исходной форме недоступна; правки и удаление будущего звонка — через его строку на панели; после удаления будущего `next_call_id` исходного пуст и поле даты снова видно; удаление исходного звонка оставляет адресата и следующий звонок
- [x] 6.5 «Нет ответа» или сделка вместе с рассылкой; действия без `madeAt`/`madeBy` — 422; дата следующего звонка в прошлом — 422 с восстановлением рассылки и даты; 403 вне области
