## Why

На панели `/dashboard` отображаются контакты организаций с кнопками-заглушками «Изменить» и «Добавить контакт», которые ведут на несуществующие маршруты (404). Менеджеры и администраторы должны иметь возможность создавать, редактировать и удалять контакты через формы, соответствующие дизайн-системе, с привязкой к организациям.

## What Changes

- **ContactController**: CRUD-контроллер с действиями create, edit, delete для контактов.
- **Страницы форм**: отдельные страницы `/contacts/new` и `/contacts/{id}/edit` с формами создания/редактирования.
- **Модальные окна**: компонент модального окна для быстрого редактирования контакта прямо из карточки на дашборде.
- **Валидация**: Symfony Validator для проверки полей (name, organization, contactType) с сообщениями об ошибках на русском языке.
- **Доступ**: проверка области доступа (ADR-0005–0008): менеджер работает только с контактами организаций своих групп, администратор — со всеми.
- **Удаление**: подтверждение удаления контакта.
- **Выбор организации**: при создании контакта указание организации из доступных.

## Capabilities

### New Capabilities

- `contacts/crud`: CRUD-операции с контактами (создание, редактирование, удаление), формы, валидация, модальные окна, проверка доступа, привязка к организации.

### Modified Capabilities

(нет изменений требований в существующих спеках — только реализация CRUD)

## Impact

- **Код**: новый `ContactController`, шаблоны форм, JavaScript для модальных окон, маршруты.
- **Дашборд**: обновление кнопок «Изменить» в карточках контактов для открытия модальных окон.
- **Дашборд**: обновление кнопки «Добавить контакт» для перехода на форму создания.
- **Безопасность**: проверка области доступа перед каждой операцией CRUD.
- **Дизайн**: формы соответствуют дизайн-системе (поля с нижним подчёркиванием, кнопки-пилюли, модальные окна без теней).
