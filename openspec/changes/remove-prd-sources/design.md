# Design: remove-prd-sources

## Context

OpenSpec объявлен единственным источником истины (ADR-0006). Спецификации
соответствуют PRD, пробелы зафиксированы. Остаток: физическое удаление PRD и
`PRD_WORKFLOW.md` и вычистка ссылок на них из репозитория.

```
         ссылки на PRD сейчас               после удаления
┌──────────────────────────────┐   ┌─────────────────────────────┐
│ docs/source/PRD.md  ──────────┤   │ (файлы удалены)            │
│   ├─ 10 × openspec/specs/*   │   │  spec-заголовки очищены     │
│   ├─ openspec/project.md      │   │  project.md → OpenSpec/ADRs │
│   ├─ openspec/config.yaml     │   │  context очищен            │
│   ├─ AGENTS.md                │   │  PRD-разделы удалены,      │
│   └─ openspec/AGENTS.md       │   │  устаревшие факты исправлены│
└──────────────────────────────┘   └─────────────────────────────┘
```

## Goals / Non-Goals

**Goals:**
- PRD и PRD_WORKFLOW физически удалены; `docs/source/` пуст.
- Ни одной ссылки на `PRD.md`/`docs/source/PRD` не осталось в активных артефактах
  (спецификации, project.md, config.yaml, AGENTS.md; ADR-0005/0006 — осознанные
  исторические упоминания, допускаются).
- AGENTS.md (оба) перестают утверждать «CLI не установлен» и «git нет».

**Non-Goals:**
- НЕ менять поведение спецификаций (`skip_specs: true`).
- НЕ трогать ADR-0005/0006 (исторические упоминания PRD там допустимы).
- НЕ добавлять новые возможности (реестр отложенных пробелов — в ADR-0006).

## Decisions

**D1. Удаление через `git rm`.**
Файлы PRD отслеживаются git; удаляем `git rm docs/source/PRD.md
docs/source/PRD_WORKFLOW.md`, затем удаляем пустую директорию.

**D2. Спец-заголовки: удалить строку «Источник: PRD.md §…», не заменяя.**
Интро-абзац после заголовка уже описывает возможность; ADR-ссылки уже есть в
intro-абзацах (`adr/0001–0004`). Добавлять новую строку-источник не требуется —
это и есть цель «полной опоры на OpenSpec».

**D3. project.md: переформулировка, а не удаление.**
Принцип №1: «OpenSpec — единственный источник истины»; Принцип №4:
«трассируемость через ADR и перекрёстные ссылки возможностей»; References:
PRD-записи удаляются, ADR-записи остаются.

**D4. AGENTS.md: фиксация актуальных фактов.**
CLI 1.8.0 установлен (`openspec --version`); git-репозиторий существует
(нужен `safe.directory`). Убираются секции «Source of truth: docs/source/PRD.md».

## Risks / Trade-offs

- [Висячие ссылки после удаления] -> Полный grep по `PRD`/`docs/source` после
  применения; ADR-0005/0006 — допустимые исторические упоминания.
- [Потеря требований] -> Реестр отложенных пробелов (ADR-0006) + сверка
  `reconcile-specs-with-prd` завершены до удаления.
- [Удаление в git безвозвратно] -> Восстановление возможно из git-истории
  (commit 76f08d4 и последующие).

## Migration Plan

1. `git rm` PRD-файлов; удалить пустой `docs/source/`.
2. Вычистить строки-источники в 10 спецификациях.
3. Обновить `project.md`, `config.yaml`, `AGENTS.md` ×2.
4. Grep-проверка остаточных ссылок; заархивировать change.
