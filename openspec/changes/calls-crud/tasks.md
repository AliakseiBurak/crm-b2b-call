- [ ] 8.1 Факт звонка определяется наличием фактической даты (без чекбокса «Звонок проведён»)

- [ ] 8.3 Администратор видит селектор «Кто совершил звонок» (админы+менеджеры) в форме и модалке

- [ ] 8.5 Запланированная дата не может быть в прошлом (сегодня разрешено)
- [ ] 8.6 Фактическая дата не может быть в будущем
- [ ] 8.7 Календарь на всех полях дат; ручной ввод; время только у фактической даты
- [ ] 8.8 Пустое поле факта предвыбирает текущие дату/время; открытие оверлея закрывает другие
- [ ] 8.9 Дефолт запланированной даты: +3 дня, выходной → понедельник
- [ ] 8.10 Форматы: плановая `d.m.Y`, фактическая `d.m.Y H:i`, без плейсхолдеров
