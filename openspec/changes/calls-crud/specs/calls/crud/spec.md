## Purpose

CRUD-операции со звонками: создание, редактирование, удаление через формы, соответствующие дизайн-системе, с фиксацией результата (рассылка/сделка/следующий звонок) и проверкой области доступа.

## ADDED Requirements

### Requirement: Менеджер планирует звонок
The system SHALL let the manager create a call with organization, contact, and scheduled date through a form.

#### Scenario: Успешное создание звонка
- **WHEN** менеджер открывает форму создания звонка для организации "ООО Ромашка"
- **AND** выбирает контакт "Иван Петров"
- **AND** указывает дату звонка "завтра"
- **AND** нажимает кнопку "Создать"
- **THEN** звонок сохраняется в системе с датой "завтра"
- **AND** менеджер перенаправляется на страницу звонка

#### Scenario: Ошибка валидации при создании
- **WHEN** менеджер открывает форму создания звонка
- **AND** оставляет поле "Дата звонка" пустым
- **AND** нажимает кнопку "Создать"
- **THEN** форма отображает ошибку "Дата звонка обязательна для заполнения"
- **AND** звонок не сохраняется

### Requirement: Менеджер фиксирует факт звонка
The system SHALL let the manager record the fact of the call (who made it and when) after the call takes place.

#### Scenario: Фиксация факта звонка
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** отмечает "звонок проведён"
- **AND** указывает дату и время звонка
- **AND** нажимает кнопку "Сохранить"
- **THEN** в истории звонков отображается, что звонок осуществил менеджер в указанные дату и время

### Requirement: Результат звонка — комбинация полей
The system SHALL let the manager record a call result as a combination of independent marks: at most one campaign, a deal, and a next call.

#### Scenario: Результат — рассылка
- **WHEN** менеджер завершает звонок по организации "ООО Ромашка"
- **AND** выбирает из списка рассылку "Новые курсы"
- **AND** нажимает кнопку "Сохранить"
- **THEN** организация "ООО Ромашка" помечается получателем рассылки "Новые курсы"

#### Scenario: Результат — сделка
- **WHEN** менеджер завершает звонок по организации "ООО Ромашка"
- **AND** отмечает "сделка совершена"
- **AND** нажимает кнопку "Сохранить"
- **THEN** в карточке звонка отображается отметка о совершённой сделке

#### Scenario: Результат — будущий звонок
- **WHEN** менеджер завершает звонок по организации "ООО Ромашка"
- **AND** указывает дату следующего звонка
- **AND** нажимает кнопку "Сохранить"
- **THEN** создаётся новый звонок с этой датой
- **AND** организация "ООО Ромашка" попадает в планирование

#### Scenario: Комбинация результатов
- **WHEN** менеджер завершает звонок по организации "ООО Ромашка"
- **AND** одновременно выбирает рассылку "Новые курсы", отмечает сделку и назначает следующий звонок
- **AND** нажимает кнопку "Сохранить"
- **THEN** все три отметки сохраняются вместе со звонком

#### Scenario: Звонок без результата
- **WHEN** менеджер завершает звонок по организации "ООО Ромашка"
- **AND** не выбирает рассылку, сделку и следующий звонок
- **AND** нажимает кнопку "Сохранить"
- **THEN** фиксируется только факт звонка (кто и когда)

### Requirement: Менеджер редактирует звонок
The system SHALL let the manager update call fields through a form.

#### Scenario: Успешное редактирование звонка
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** изменяет заметки
- **AND** нажимает кнопку "Сохранить"
- **THEN** заметки звонка обновляются
- **AND** менеджер перенаправляется на страницу звонка

#### Scenario: Ошибка валидации при редактировании
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** очищает поле "Дата звонка"
- **AND** нажимает кнопку "Сохранить"
- **THEN** форма отображает ошибку "Дата звонка обязательна для заполнения"
- **AND** звонок не обновляется

### Requirement: Удаление звонка
The system SHALL let the manager delete calls they have access to.

#### Scenario: Успешное удаление звонка
- **WHEN** менеджер нажимает кнопку "Удалить" на странице звонка
- **AND** подтверждает удаление
- **THEN** звонок удаляется из системы
- **AND** менеджер перенаправляется на список звонков организации

#### Scenario: Отмена удаления звонка
- **WHEN** менеджер нажимает кнопку "Удалить" на странице звонка
- **AND** отменяет удаление
- **THEN** звонок остаётся в системе

### Requirement: Модальное окно быстрого редактирования
The system SHALL provide a modal window for quick call editing from the dashboard without page reload.

#### Scenario: Открытие модального окна
- **WHEN** пользователь нажимает кнопку "Изменить" в строке звонка на дашборде
- **THEN** открывается модальное окно с формой редактирования звонка
- **AND** данные звонка загружаются в форму

#### Scenario: Сохранение изменений в модальном окне
- **WHEN** пользователь изменяет заметки в модальном окне
- **AND** нажимает кнопку "Сохранить"
- **THEN** изменения сохраняются
- **AND** модальное окно закрывается
- **AND** строка звонка на дашборде обновляется без перезагрузки страницы

#### Scenario: Закрытие модального окна
- **WHEN** пользователь нажимает кнопку "Отмена" или крестик в модальном окне
- **THEN** модальное окно закрывается
- **AND** изменения не сохраняются

### Requirement: Форма соответствует дизайн-системе
The system SHALL render call forms with the established design system: underline inputs, pill buttons, no shadows.

#### Scenario: Поле формы с оранжевым подчёркиванием
- **WHEN** пользователь открывает форму звонка
- **THEN** каждое текстовое поле отображается без рамки и фона
- **AND** под полем — линия толщиной 2px цвета `#d66a2b`
- **AND** текст и плейсхолдер поля окрашены в `#d66a2b`

#### Scenario: Кнопки формы
- **WHEN** пользователь открывает форму звонка
- **THEN** кнопка "Создать/Сохранить" — оранжевая градиентная пилюля
- **AND** кнопка "Отмена/Удалить" — серая пилюля
