## Why

На панели `/dashboard` отображаются звонки организаций с кнопками-заглушками «Изменить» и «Добавить звонок», которые ведут на несуществующие маршруты (404). Менеджеры должны иметь возможность планировать звонки, фиксировать результат (рассылка/сделка/следующий звонок) и редактировать существующие звонки через формы, соответствующие дизайн-системе.

## What Changes

- **CallController**: CRUD-контроллер с действиями create, edit, delete для звонков.
- **Страницы форм**: отдельные страницы `/organizations/{id}/calls/new` и `/calls/{id}/edit` с формами создания/редактирования.
- **Модальные окна**: компонент модального окна для быстрого редактирования звонка прямо из раскрытой секции организации на дашборде.
- **Валидация**: Symfony Validator для проверки полей (organization, scheduledAt, contact) с сообщениями об ошибках на русском языке.
- **Доступ**: проверка области доступа (ADR-0005–0008): менеджер работает только со звонками организаций своих групп, администратор — со всеми.
- **Удаление**: подтверждение удаления звонка.
- **Результат звонка**: комбинация независимых полей (рассылка + сделка + следующий звонок).

## Capabilities

### New Capabilities

- `calls/crud`: CRUD-операции со звонками (создание, редактирование, удаление), формы, валидация, модальные окна, проверка доступа, фиксация результата.

### Modified Capabilities

(нет изменений требований в существующих спеках — только реализация CRUD)

## Impact

- **Код**: новый `CallController`, шаблоны форм, JavaScript для модальных окон, маршруты.
- **Дашборд**: обновление кнопок «Изменить» в списке звонков для открытия модальных окон.
- **Дашборд**: обновление кнопки «Добавить звонок» для перехода на форму создания.
- **Безопасность**: проверка области доступа перед каждой операцией CRUD.
- **Дизайн**: формы соответствуют дизайн-системе (поля с нижним подчёркиванием, кнопки-пилюли, модальные окна без теней).
