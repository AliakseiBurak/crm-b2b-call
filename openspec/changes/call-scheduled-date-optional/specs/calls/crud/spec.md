## MODIFIED Requirements

### Requirement: Менеджер планирует звонок
The system SHALL let the manager create a call with organization, contact,
and an optional scheduled date, and SHALL also let the manager record a
completed call by filling only the actual call date.

#### Scenario: Успешное создание звонка
- **WHEN** менеджер открывает форму создания звонка для организации "ООО Ромашка"
- **AND** выбирает контакт "Иван Петров"
- **AND** указывает запланированную дату "завтра"
- **AND** нажимает кнопку "Создать"
- **THEN** звонок сохраняется в системе с датой "завтра"
- **AND** менеджер перенаправляется на панель организаций
- **AND** организация "ООО Ромашка" выделена в таблице панели

#### Scenario: Создание проведённого звонка без запланированной даты
- **WHEN** менеджер открывает форму создания звонка для организации "ООО Ромашка"
- **AND** оставляет поле "Запланированная дата звонка" пустым
- **AND** указывает фактические дату и время в прошлом
- **AND** нажимает кнопку "Создать"
- **THEN** звонок сохраняется без запланированной даты
- **AND** звонок считается проведённым с указанными датой и временем

#### Scenario: Ошибка валидации при создании
- **WHEN** менеджер указывает в поле "Запланированная дата звонка" дату в прошлом
- **AND** нажимает кнопку "Создать"
- **THEN** форма отображает ошибку "Запланированная дата звонка не может быть в прошлом"
- **AND** введённые значения полей формы восстанавливаются
- **AND** звонок не сохраняется

#### Scenario: Ошибка фактической даты восстанавливает значения
- **WHEN** менеджер указывает в поле "Фактическая дата звонка" дату в будущем
- **AND** нажимает кнопку "Создать"
- **THEN** форма отображает ошибку "Фактическая дата звонка не может быть в будущем"
- **AND** введённые значения полей формы восстанавливаются
- **AND** звонок не сохраняется

## MODIFIED Requirements

### Requirement: Менеджер редактирует звонок
The system SHALL let the manager update call fields through a form.

#### Scenario: Успешное редактирование звонка
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** изменяет заметки
- **AND** нажимает кнопку "Сохранить"
- **THEN** заметки звонка обновляются
- **AND** менеджер перенаправляется на страницу звонка

#### Scenario: Ошибка валидации при редактировании
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** указывает в поле "Запланированная дата звонка" дату в прошлом
- **AND** нажимает кнопку "Сохранить"
- **THEN** форма отображает ошибку "Запланированная дата звонка не может быть в прошлом"
- **AND** введённые значения полей формы восстанавливаются
- **AND** звонок не обновляется

#### Scenario: Очистка запланированной даты сохраняет звонок
- **WHEN** менеджер открывает форму редактирования звонка
- **AND** очищает поле "Запланированная дата звонка"
- **AND** нажимает кнопку "Сохранить"
- **THEN** звонок сохраняется без запланированной даты
- **AND** остальные поля звонка не изменяются
