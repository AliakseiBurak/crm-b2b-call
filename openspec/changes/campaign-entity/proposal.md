## Why

Сущность `Campaign` выделена в отдельный функционал. Кампания хранит тему письма,
шаблон письма и вложения непосредственно на себе (отдельная сущность «компания
рассылок» / провайдер / канал доставки не
создаётся — используется только email-канал), связывается со звонками, поддерживает
запуск (ручной или автоматический при завершении звонка) и защиту от удаления пока
есть связанные звонки. Реализуется до `call-result-entity` (внешний ключ `campaign_id`
на `CallResult`).

## What Changes

- Сущность `Campaign`: `name`, `subject` (тема письма), `template` (текст шаблона письма), `status` (enum: draft/launched/archived, default draft), `link_calls` (bool),
  `auto_launch` (bool), `launched_at` (nullable), `created_at`; вложения через таблицу `campaign_attachment`
- Вложения кампании (файлы) хранятся в отдельной таблице `campaign_attachment`
  (`id`, `campaign_id` FK, `filename`, `storage_key`, `mime_type`, `size`)
- Связь со звонками через `CallResult.campaign_id`; защита от удаления, пока есть ссылающиеся результаты
- Ручной запуск (кнопка/флаг) и авто-запуск (при завершении звонка с результатом рассылки по этой кампании)
- **Только флаг запуска**: фактическая отправка (outbox/SMTP/статусы писем по ADR-0010) — в будущем сервисе MailingService
- Примирение спецификации `campaigns`: шаблон и вложения — на самой кампании (без отдельной сущности компании рассылок); курсы вне scope данного изменения

## Capabilities

### New Capabilities
- (нет новых возможностей; модификация существующей)

### Modified Capabilities
- `campaigns`: Campaign хранит шаблон и вложения; добавлены `link_calls`, `auto_launch`,
  защита от удаления при связанных звонках, запуск (ручной/авто); курсы вне scope

## Impact

- **Сущности Doctrine**: расширение `Campaign` (новые поля + вложения)
- **Миграция БД**: изменение таблицы `campaign` (template, link_calls, auto_launch, launched_at) + таблица `campaign_attachment`
- **Контроллеры**: `CampaignController` — создание/редактирование (admin+managers), загрузка вложений, кнопка запуска, защита удаления
- **Шаблоны**: карточка кампании, кнопка «Запустить», индикация связанных звонков
- **Связь**: `CallResult` (в изменении `call-result-entity`) ссылается на Campaign; авто-запуск — хук при создании результата
- **Зависимости**: нет фундаментальных; `call-result-entity` зависит от этого изменения
