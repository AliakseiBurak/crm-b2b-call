# Email Campaigns

Источник: PRD.md §2.6, §3.5 (архивирован в `docs/source/PRD.md`).
Модуль маркетинговых рассылок: пакетная отправка email по группам контактов,
отслеживание статусов доставки и обработка отписок.

```gherkin
Feature: Email Campaigns

  Rule: Пакетная рассылка по группам контактов
    Система ДОЛЖНА выполнять пакетную отправку email-рассылки, созданной в
    рамках организации, по целевой группе контактов (см. `contact-groups`);
    каждая рассылка ДОЛЖНА быть привязана к организации.

    Scenario: Отправка рассылки по группе
      Given группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
      And для организации "ООО Ромашка" создана рассылка "Новые курсы"
      When система отправляет рассылку "Новые курсы" по группе "Ключевые клиенты"
      Then контакт "Иван Петров" получает письмо с темой "Новые курсы"

  Rule: Отслеживание статусов рассылки
    Система ДОЛЖНА отслеживать статус каждого письма рассылки: sent, delivered,
    opened, bounced.

    Scenario: Смена статуса письма
      Given письмо рассылки отправлено контакту "Иван Петров"
      When письмо доставлено и открыто получателем
      Then статус письма становится opened

    Scenario: Фиксация недоставленного письма
      Given письмо рассылки отправлено контакту с недостоверным адресом
      When почтовый сервер возвращает ошибку доставки
      Then статус письма становится bounced

  Rule: Обработка отписки
    Система ДОЛЖНА обрабатывать запросы на отписку и исключать отписавшихся
    контактов из последующих рассылок.

    Scenario: Отписка контакта от рассылок
      Given контакт "Иван Петров" получил рассылку "Новые курсы"
      When он переходит по ссылке отписки
      Then контакт "Иван Петров" исключается из последующих рассылок

    Scenario: Рассылка не включает отписавшихся
      Given контакт "Иван Петров" отписался от рассылок
      When система отправляет новую рассылку по группе "Ключевые клиенты"
      Then контакт "Иван Петров" не получает письмо новой рассылки
```
