# Email Campaigns

Модуль маркетинговых рассылок: пакетная отправка email по группам контактов,
отслеживание статусов доставки и обработка отписок.

## Purpose

Маркетинговые рассылки: пакетная отправка email по группам контактов,
отслеживание статусов доставки и обработка отписок.

## Requirements

### Requirement: Пакетная рассылка по группам контактов
The system SHALL send a batch email campaign created within an organization to
a target contact group (see `contact-groups`); each campaign SHALL be bound to
an organization.

#### Scenario: Отправка рассылки по группе
- **WHEN** группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
- **AND** для организации "ООО Ромашка" создана рассылка "Новые курсы"
- **AND** система отправляет рассылку "Новые курсы" по группе "Ключевые клиенты"
- **THEN** контакт "Иван Петров" получает письмо с темой "Новые курсы"

### Requirement: Отслеживание статусов рассылки
The system SHALL track the status of each campaign email: sent, delivered,
opened, bounced.

#### Scenario: Смена статуса письма
- **WHEN** письмо рассылки отправлено контакту "Иван Петров"
- **AND** письмо доставлено и открыто получателем
- **THEN** статус письма становится opened

#### Scenario: Фиксация недоставленного письма
- **WHEN** письмо рассылки отправлено контакту с недостоверным адресом
- **AND** почтовый сервер возвращает ошибку доставки
- **THEN** статус письма становится bounced

### Requirement: Обработка отписки
The system SHALL process unsubscribe requests and SHALL exclude unsubscribed
contacts from later campaigns.

#### Scenario: Отписка контакта от рассылок
- **WHEN** контакт "Иван Петров" получил рассылку "Новые курсы"
- **AND** он переходит по ссылке отписки
- **THEN** контакт "Иван Петров" исключается из последующих рассылок

#### Scenario: Рассылка не включает отписавшихся
- **WHEN** контакт "Иван Петров" отписался от рассылок
- **AND** система отправляет новую рассылку по группе "Ключевые клиенты"
- **THEN** контакт "Иван Петров" не получает письмо новой рассылки
