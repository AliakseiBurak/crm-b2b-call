# Contact Groups

Группы контактов позволяют группировать контакты по назначению и статусу и
используются для целенаправленной доставки email-рассылок. Каждая группа
привязана к организации. Не путать с `OrganizationGroup` — группами организаций.

## Purpose

Группы контактов группируют контакты по назначению и статусу и используются
как адресная аудитория целенаправленных email-рассылок; каждая группа
привязана к организации.

## Requirements

### Requirement: Создание групп контактов
The system SHALL allow creating contact groups with a name bound to an
organization and SHALL list all contact groups.

#### Scenario: Создание группы контактов
- **WHEN** в системе существует организация "ООО Ромашка"
- **AND** пользователь создаёт группу контактов "Ключевые клиенты" для организации "ООО Ромашка"
- **THEN** группа контактов "Ключевые клиенты" появляется в списке групп

### Requirement: Добавление и удаление контактов из группы
The system SHALL add contacts to a group, store their identifiers in the group
membership, and remove them from the group.

#### Scenario: Добавление контакта в группу
- **WHEN** существует группа контактов "Ключевые клиенты"
- **AND** в системе существует контакт "Иван Петров"
- **AND** пользователь добавляет контакт "Иван Петров" в группу "Ключевые клиенты"
- **THEN** группа "Ключевые клиенты" содержит контакт "Иван Петров"

#### Scenario: Удаление контакта из группы
- **WHEN** группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
- **AND** пользователь удаляет контакт "Иван Петров" из группы
- **THEN** группа "Ключевые клиенты" больше не содержит контакт "Иван Петров"

### Requirement: Использование групп для целевых рассылок
Contact groups SHALL be used as the target audience of batch email campaigns
(see `email-campaigns`).

#### Scenario: Рассылка по группе контактов
- **WHEN** группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
- **AND** система выполняет рассылку по группе "Ключевые клиенты"
- **THEN** контакт "Иван Петров" получает письмо рассылки
