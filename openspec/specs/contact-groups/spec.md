# Contact Groups

Источник: PRD.md §2.8, §4.2 (архивирован в `docs/source/PRD.md`).
Группы контактов позволяют группировать контакты по назначению и статусу и
используются для целенаправленной доставки email-рассылок. Каждая группа
привязана к организации. Не путать с `OrganizationGroup` — группами организаций.

```gherkin
Feature: Contact Groups

  Rule: Создание групп контактов
    Система ДОЛЖНА позволять создавать группы контактов с названием, привязанные
    к организации, и просматривать список всех групп контактов.

    Scenario: Создание группы контактов
      Given в системе существует организация "ООО Ромашка"
      When пользователь создаёт группу контактов "Ключевые клиенты" для организации "ООО Ромашка"
      Then группа контактов "Ключевые клиенты" появляется в списке групп

  Rule: Добавление и удаление контактов из группы
    Система ДОЛЖНА добавлять контакты в группу, содержать их идентификаторы в
    составе группы и удалять их из группы.

    Scenario: Добавление контакта в группу
      Given существует группа контактов "Ключевые клиенты"
      And в системе существует контакт "Иван Петров"
      When пользователь добавляет контакт "Иван Петров" в группу "Ключевые клиенты"
      Then группа "Ключевые клиенты" содержит контакт "Иван Петров"

    Scenario: Удаление контакта из группы
      Given группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
      When пользователь удаляет контакт "Иван Петров" из группы
      Then группа "Ключевые клиенты" больше не содержит контакт "Иван Петров"

  Rule: Использование групп для целевых рассылок
    Группы контактов ДОЛЖНЫ использоваться как адресная аудитория пакетных
    email-рассылок (см. `email-campaigns`).

    Scenario: Рассылка по группе контактов
      Given группа контактов "Ключевые клиенты" содержит контакт "Иван Петров"
      When система выполняет рассылку по группе "Ключевые клиенты"
      Then контакт "Иван Петров" получает письмо рассылки
```
