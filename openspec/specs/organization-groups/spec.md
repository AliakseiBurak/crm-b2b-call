# Organization Groups

Источник: PRD.md §2.9–2.12, §3.7, §4.4 (архивирован в `docs/source/PRD.md`).
Группы организаций распределяют организации между менеджерами. У каждого
менеджера есть собственная группа (own), создаваемая автоматически;
администратор создаёт дополнительные группы (custom) и назначает их менеджерам.
Организация может состоять в нескольких группах одновременно
(`OrganizationGroupMembership`). Длительные решения зафиксированы в
ADR-0001 и ADR-0002.

```gherkin
Feature: Organization Groups

  Rule: При создании менеджера автоматически создаётся его собственная группа
    Система ДОЛЖНА автоматически создавать группу типа own при создании
    менеджера, и создаваемые менеджером организации ДОЛЖНЫ попадать в неё
    автоматически.

    Scenario: Создание менеджера создаёт own group
      Given администратор создаёт менеджера "Иван Петров"
      Then в системе появляется группа типа own, связанная с менеджером "Иван Петров"

    Scenario: Новая организация менеджера попадает в его own group
      Given у менеджера "Иван Петров" есть собственная группа
      When менеджер создаёт организацию "ООО Ромашка"
      Then организация "ООО Ромашка" добавляется в его собственную группу

  Rule: Администратор управляет custom-группами
    Администратор ДОЛЖЕН иметь возможность создавать, изменять и удалять
    custom-группы, а также назначать их менеджерам и переносить организации
    между группами.

    Scenario: Админ создаёт custom-группу и назначает её менеджеру
      Given аутентифицированный администратор
      When он создаёт custom-группу "Регион Север" и назначает её менеджеру "Иван Петров"
      Then менеджер "Иван Петров" получает доступ к организациям группы "Регион Север"

    Scenario: Админ переносит организацию между группами
      Given организация "ООО Ромашка" состоит в группе "Регион Север"
      When администратор переносит её в группу "Регион Юг"
      Then организация "ООО Ромашка" состоит в группах "Регион Север" и "Регион Юг"

  Rule: Членство организации в группах является many-to-many
    Организация ДОЛЖНА иметь возможность состоять одновременно в нескольких
    группах через `OrganizationGroupMembership`, и одна группа МОЖЕТ быть
    назначена нескольким менеджерам через `GroupAssignment`.

    Scenario: Одна группа назначается нескольким менеджерам
      Given custom-группа "Регион Север" назначена менеджеру "Иван Петров"
      When администратор назначает группу "Регион Север" менеджеру "Мария Смирнова"
      Then оба менеджера имеют доступ к организациям группы "Регион Север"
```
