# Calls

Источник: PRD.md §2.5, §3.4 (архивирован в `docs/source/PRD.md`).
Модуль телемаркетинговых звонков: планирование по календарю, ведение плана
разговора, фиксация содержания и результата, хранение записи разговора и
генерация писем по результатам звонка.

```gherkin
Feature: Calls

  Rule: Планирование звонков
    Система ДОЛЖНА позволять менеджеру планировать звонки с указанием даты,
    организации, контакта и предварительного плана разговора.

    Scenario: Создание запланированного звонка
      Given в системе существует организация "ООО Ромашка" и контакт "Иван Петров"
      When менеджер планирует звонок контакту "Иван Петров" на завтра с планом разговора
      Then звонок появляется в календаре менеджера с указанным планом

  Rule: Фиксация содержания и результата звонка
    Система ДОЛЖНА хранить дату звонка, длительность, ссылку на запись,
    содержание (заметки) и результат звонка.

    Scenario: Запись результата звонка
      Given звонок контакту "Иван Петров" состоялся
      When менеджер фиксирует содержание, результат "Интересуется курсами" и ссылку на запись
      Then в истории звонков организации "ООО Ромашка" отображается звонок с результатом "Интересуется курсами"

  Rule: Хранение записи разговора
    Система ДОЛЖНА хранить запись разговора по внешней ссылке
    (`recording_url`), позволяющей воспроизводить и анализировать разговор.

    Scenario: Анализ записи разговора
      Given звонок контакту "Иван Петров" имеет ссылку на запись разговора
      When менеджер открывает историю звонков организации "ООО Ромашка"
      Then он может прослушать запись разговора звонка

  Rule: Генерация писем по результатам звонка
    Система ДОЛЖНА генерировать персонализированное письмо на основе результата
    звонка и шаблона коммуникаций (см. `communication-templates`).

    Scenario: Генерация письма после звонка
      Given звонок завершён с результатом "Интересуется курсами"
      When система генерирует письмо по результатам звонка
      Then письмо формируется с учётом результата звонка и шаблона
```
