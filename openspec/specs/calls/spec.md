# Calls

Модуль телемаркетинговых звонков: планирование по календарю, ведение плана
разговора, фиксация содержания и результата, хранение записи разговора и
генерация писем по результатам звонка.

## Purpose

Телемаркетинговые звонки: планирование по календарю, ведение плана разговора,
фиксация содержания и результата, хранение записи и генерация писем по
результатам звонка.

## Requirements

### Requirement: Планирование звонков
The system SHALL let a manager schedule calls with a date, organization,
contact, and a preliminary call plan.

#### Scenario: Создание запланированного звонка
- **WHEN** в системе существует организация "ООО Ромашка" и контакт "Иван Петров"
- **AND** менеджер планирует звонок контакту "Иван Петров" на завтра с планом разговора
- **THEN** звонок появляется в календаре менеджера с указанным планом

### Requirement: Фиксация содержания и результата звонка
The system SHALL store the call date, duration, recording link, content
(notes), and result.

#### Scenario: Запись результата звонка
- **WHEN** звонок контакту "Иван Петров" состоялся
- **AND** менеджер фиксирует содержание, результат "Интересуется курсами" и ссылку на запись
- **THEN** в истории звонков организации "ООО Ромашка" отображается звонок с результатом "Интересуется курсами"

### Requirement: Хранение записи разговора
The system SHALL store the call recording by external link (`recording_url`)
so the conversation can be played back and analyzed.

#### Scenario: Анализ записи разговора
- **WHEN** звонок контакту "Иван Петров" имеет ссылку на запись разговора
- **AND** менеджер открывает историю звонков организации "ООО Ромашка"
- **THEN** он может прослушать запись разговора звонка

### Requirement: Генерация писем по результатам звонка
The system SHALL generate a personalized letter based on the call result and a
communication template (see `communication-templates`).

#### Scenario: Генерация письма после звонка
- **WHEN** звонок завершён с результатом "Интересуется курсами"
- **AND** система генерирует письмо по результатам звонка
- **THEN** письмо формируется с учётом результата звонка и шаблона
