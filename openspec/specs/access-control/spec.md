# Access Control

Права доступа определяются ролями пользователя и группами организаций.
Менеджер имеет полный доступ к организациям своей own и назначенных групп;
администратор видит всё и управляет группами и назначениями. Длительные
решения зафиксированы в ADR-0001–0004.

```gherkin
Feature: Access Control

  Rule: Система определяет роли пользователей
    Система ДОЛЖНА назначать каждому пользователю одну из фиксированных ролей:
    admin, manager. Набор ролей фиксирован: создание, изменение и удаление ролей
    не поддерживаются (эндпоинты Roles CRUD не реализуются, см. ADR-0005).

    Scenario: Назначение роли при создании пользователя
      Given администратор создаёт пользователя "Мария Смирнова"
      When он назначает ей роль manager
      Then пользователь "Мария Смирнова" получает роль manager

    Scenario: Система отклоняет создание произвольной роли
      Given аутентифицированный администратор
      When он пытается создать новую роль "supervisor"
      Then система отклоняет операцию создания роли

  Rule: Менеджер имеет полный доступ к организациям своих групп
    Менеджер ДОЛЖЕН иметь полный доступ ко всем организациям своей own группы
    и всем назначенным ему custom-группам, включая контакты, звонки и рассылки
    этих организаций.

    Scenario: Менеджер получает доступ к организациям назначенных групп
      Given менеджер "Иван Петров" имеет own group и назначенную custom-группу "Регион Север"
      When менеджер открывает список организаций
      Then он видит организации своей own группы и группы "Регион Север"

    Scenario: Менеджер не видит организации вне своих групп
      Given менеджер "Иван Петров" не имеет доступа к организации "ООО Конкурент"
      When менеджер выполняет поиск организаций
      Then организация "ООО Конкурент" не отображается в результатах

  Rule: Администратор видит все организации и группы
    Администратор ДОЛЖЕН видеть все организации и группы, управлять составом
    групп и назначениями менеджеров.

    Scenario: Админ видит все организации
      Given в системе существуют организации в разных группах
      When администратор открывает список организаций
      Then он видит все организации без ограничений

    Scenario: Админ управляет назначениями групп
      Given администратор аутентифицирован
      When он назначает и снимает группы менеджерам
      Then изменения доступа применяются сразу
```
