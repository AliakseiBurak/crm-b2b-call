## Purpose

CRUD-операции с организациями: создание, редактирование, удаление через формы, соответствующие дизайн-системе, с проверкой области доступа.

## Requirements

### Requirement: Администратор создаёт организацию
The system SHALL let the administrator create an organization with name and industry through a form, and SHALL validate required fields.

#### Scenario: Успешное создание организации
- **WHEN** администратор открывает форму создания организации
- **AND** вводит название "ООО Ромашка" и отрасль "IT"
- **AND** нажимает кнопку "Создать"
- **THEN** организация "ООО Ромашка" сохраняется в системе
- **AND** администратор перенаправляется на панель
- **AND** созданная организация подсвечена в таблице организаций

#### Scenario: Ошибка валидации при создании
- **WHEN** администратор открывает форму создания организации
- **AND** оставляет поле "Название" пустым
- **AND** нажимает кнопку "Создать"
- **THEN** форма отображает ошибку "Название обязательно для заполнения"
- **AND** организация не сохраняется

### Requirement: Менеджер создаёт организацию в своей группе
The system SHALL let the manager create an organization, and SHALL automatically add it to the manager's personal group `user-<id>-group`.

#### Scenario: Менеджер создаёт организацию
- **WHEN** менеджер открывает форму создания организации
- **AND** вводит название "ООО Ромашка" и отрасль "IT"
- **AND** нажимает кнопку "Создать"
- **THEN** организация "ООО Ромашка" сохраняется в системе
- **AND** организация добавляется в группу менеджера `user-<id>-group`

### Requirement: Администратор редактирует организацию
The system SHALL let the administrator update organization name and industry through a form.

#### Scenario: Успешное редактирование организации
- **WHEN** администратор открывает форму редактирования организации "ООО Ромашка"
- **AND** изменяет отрасль на "Маркетинг"
- **AND** нажимает кнопку "Сохранить"
- **THEN** отрасль организации становится "Маркетинг"
- **AND** администратор перенаправляется на панель
- **AND** отредактированная организация подсвечена в таблице организаций

#### Scenario: Ошибка валидации при редактировании
- **WHEN** администратор открывает форму редактирования организации "ООО Ромашка"
- **AND** очищает поле "Название"
- **AND** нажимает кнопку "Сохранить"
- **THEN** форма отображает ошибку "Название обязательно для заполнения"
- **AND** организация не обновляется

### Requirement: Менеджер редактирует видимую организацию
The system SHALL let the manager update only the organizations visible to them (own `user-<id>-group` + assigned groups).

#### Scenario: Менеджер редактирует видимую организацию
- **WHEN** менеджер открывает форму редактирования организации "ООО Ромашка"
- **AND** организация видима менеджеру
- **AND** изменяет отрасль на "Маркетинг"
- **AND** нажимает кнопку "Сохранить"
- **THEN** отрасль организации становится "Маркетинг"

#### Scenario: Менеджер не может редактировать невидимую организацию
- **WHEN** менеджер пытается открыть форму редактирования организации "ООО Завод"
- **AND** организация отсутствует в области доступа менеджера
- **THEN** система отклоняет запрос с ошибкой доступа

### Requirement: Удаление организации
The system SHALL let the administrator delete an organization, and SHALL cascade delete all contacts of that organization.

#### Scenario: Успешное удаление организации
- **WHEN** администратор нажимает кнопку "Удалить" на странице организации "ООО Ромашка"
- **AND** подтверждает удаление
- **THEN** организация "ООО Ромашка" удаляется из системы
- **AND** все контакты организации удаляются каскадно
- **AND** администратор перенаправляется на список организаций

#### Scenario: Отмена удаления организации
- **WHEN** администратор нажимает кнопку "Удалить" на странице организации "ООО Ромашка"
- **AND** отменяет удаление
- **THEN** организация "ООО Ромашка" остаётся в системе

### Requirement: Модальное окно быстрого редактирования
The system SHALL provide a modal window for quick organization editing from the dashboard table without page reload. The modal SHALL contain a Delete button that navigates to the delete confirmation page.

#### Scenario: Открытие модального окна
- **WHEN** пользователь нажимает кнопку "Изменить" в строке организации на дашборде
- **THEN** открывается модальное окно с формой редактирования организации
- **AND** данные организации загружаются в форму
- **AND** кнопка "Удалить" ссылается на страницу подтверждения удаления организации

#### Scenario: Сохранение изменений в модальном окне
- **WHEN** пользователь изменяет отрасль в модальном окне
- **AND** нажимает кнопку "Сохранить"
- **THEN** изменения сохраняются
- **AND** модальное окно закрывается
- **AND** таблица на дашборде обновляется без перезагрузки страницы

#### Scenario: Закрытие модального окна
- **WHEN** пользователь нажимает кнопку "Отмена" или крестик в модальном окне
- **THEN** модальное окно закрывается
- **AND** изменения не сохраняются

### Requirement: Форма соответствует дизайн-системе
The system SHALL render organization forms with the established design system: underline inputs, pill buttons, no shadows.

#### Scenario: Поле формы с оранжевым подчёркиванием
- **WHEN** пользователь открывает форму организации
- **THEN** каждое текстовое поле отображается без рамки и фона
- **AND** под полем — линия толщиной 2px цвета `#d66a2b`
- **AND** текст и плейсхолдер поля окрашены в `#d66a2b`

#### Scenario: Кнопки формы
- **WHEN** пользователь открывает форму организации
- **THEN** кнопка "Создать/Сохранить" — оранжевая градиентная пилюля
- **AND** кнопка "Отмена/Удалить" — серая пилюля

### Requirement: Название организации — ссылка на страницу редактирования
The system SHALL render the organization name in the dashboard table as a hyperlink to the organization's edit page.

#### Scenario: Название организации является ссылкой
- **WHEN** пользователь открывает панель
- **THEN** название каждой организации в таблице отображается как ссылка
- **AND** ссылка ведёт на страницу редактирования соответствующей организации
