# Organizations

Источник: PRD.md §2.1, §3.1, §4.1 (архивирован в `docs/source/PRD.md`).
Организация — центральная сущность CRM: карточка компании, к которой привязаны
контакты, звонки, рассылки и предложения курсов. Видимость организаций
определяется моделью доступа (`adr/0001–0004`): менеджер видит организации
своей own и назначенных групп, администратор — все.

```gherkin
Feature: Organizations

  Rule: Администратор управляет карточками организаций
    Система ДОЛЖНА позволять администратору создавать, просматривать, изменять
    и удалять организации, а также получать детали организации по идентификатору.

    Scenario: Админ создаёт организацию
      Given аутентифицированный администратор
      When он создаёт организацию с названием "ООО Ромашка" и отраслью "IT"
      Then в системе появляется организация "ООО Ромашка" с отраслью "IT"

    Scenario: Админ обновляет организацию
      Given в системе существует организация "ООО Ромашка" с отраслью "IT"
      When администратор изменяет её отрасль на "Маркетинг"
      Then отрасль организации становится "Маркетинг"

    Scenario: Админ удаляет организацию
      Given в системе существует организация "ООО Ромашка"
      When администратор удаляет её
      Then организация "ООО Ромашка" больше не отображается в списке

  Rule: Поиск организаций по названию и отрасли
    Система ДОЛЖНА искать организации по названию и отрасли; результаты поиска
    ДОЛЖНЫ возвращаться за время менее 500 мс.

    Scenario: Поиск по названию
      Given в системе есть организации "ООО Ромашка" и "ОАО Завод"
      When пользователь выполняет поиск по слову "Ромашка"
      Then в результатах есть только организация "ООО Ромашка"

    Scenario: Поиск по отрасли
      Given в системе есть организации с отраслями "IT" и "Маркетинг"
      When пользователь применяет фильтр по отрасли "Маркетинг"
      Then в результатах есть только организации с отраслью "Маркетинг"

  Rule: Синхронизация организаций из внешних источников
    Система ДОЛЖНА поддерживать импорт организаций из внешних источников и
    актуализировать карточки существующих организаций.

    Scenario: Импорт новой организации
      Given во внешнем источнике есть организация "ООО Новый клиент"
      When система выполняет синхронизацию из внешнего источника
      Then в системе появляется организация "ООО Новый клиент"
```
