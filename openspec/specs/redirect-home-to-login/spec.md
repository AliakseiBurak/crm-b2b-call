## Purpose

Определяет поведение домашней страницы `/` для неаутентифицированных
пользователей: вместо отображения hero-страницы система перенаправляет
на страницу входа.

## ADDED Requirements

### Requirement: Домашняя страница перенаправляет гостей на вход
The system SHALL redirect unauthenticated users from `/` to `/login`
instead of rendering the hero landing page. Authenticated users SHALL
continue to see the home page with statistics.

#### Scenario: Неаутентифицированный пользователь попадает на /
- **WHEN** неаутентифицированный пользователь открывает страницу `/`
- **THEN** система перенаправляет на страницу входа `/login`

#### Scenario: Аутентифицированный пользователь видит домашнюю страницу
- **WHEN** аутентифицированный пользователь открывает страницу `/`
- **THEN** система отображает домашнюю страницу со статистикой

#### Scenario: Гость на /login после редиректа
- **WHEN** неаутентифицированный пользователь перенаправлен на `/login`
  и успешно входит в систему
- **THEN** система перенаправляет на домашнюю страницу `/`
