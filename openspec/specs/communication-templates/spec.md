# Communication Templates

Шаблоны коммуникаций — готовые тексты для быстрых ответов контактам и для
генерации писем по результатам звонков. Используются операторами и менеджерами
для ускорения переговоров.

```gherkin
Feature: Communication Templates

  Rule: Управление шаблонами коммуникаций
    Система ДОЛЖНА позволять создавать, просматривать и изменять шаблоны
    коммуникаций, хранящие структуру письма (тема и тело).

    Scenario: Создание шаблона
      Given аутентифицированный пользователь
      When он создаёт шаблон "Знакомство с курсами" с темой и телом письма
      Then шаблон "Знакомство с курсами" появляется в списке шаблонов

    Scenario: Просмотр списка шаблонов
      Given в системе есть шаблоны "Знакомство с курсами" и "Напоминание о звонке"
      When пользователь открывает список шаблонов коммуникаций
      Then он видит оба шаблона

  Rule: Использование шаблонов для быстрых ответов
    Операторы и менеджеры ДОЛЖНЫ использовать шаблоны для быстрых ответов
    контактам без повторного ввода текста.

    Scenario: Быстрый ответ по шаблону
      Given существует шаблон "Знакомство с курсами"
      When оператор выбирает шаблон для ответа контакту
      Then письмо контакту формируется из темы и тела шаблона "Знакомство с курсами"

  Rule: Генерация писем по результатам звонка
    Система ДОЛЖНА использовать шаблоны при генерации письма по результатам
    звонка (см. `calls`).

    Scenario: Письмо после звонка на основе шаблона
      Given звонок завершён с результатом "Интересуется курсами"
      And существует шаблон "Знакомство с курсами"
      When система генерирует письмо по результатам звонка
      Then письмо формируется на основе шаблона "Знакомство с курсами"
```
