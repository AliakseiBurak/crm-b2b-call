# Integrations

Внешние интеграции: подключение телефонных систем, интеграция с API обучающих
платформ, использование email-сервисов (SMTP, SendGrid и др.), безопасный доступ
к API через OAuth2/JWT и хранение файлов (записей звонков, сертификатов) в
S3/ MinIO.

```gherkin
Feature: Integrations

  Rule: Подключение к телефонным системам
    Система ДОЛЖНА подключаться к телефонным системам для планирования звонков
    и получения записей разговоров.

    Scenario: Подключение телефонной системы
      Given администратор настроил интеграцию с телефонной системой
      When система получает запись разговора из телефонной системы
      Then запись сохраняется по ссылке в карточке звонка

  Rule: Интеграция с API обучающих платформ
    Система ДОЛЖНА интегрироваться с API обучающих платформ для получения
    данных о курсах, пройденных программах и сертификатах.

    Scenario: Получение данных платформы
      Given интеграция с обучающей платформой настроена
      When система запрашивает сведения о завершённом курсе организации "ООО Ромашка"
      Then в системе отображается пройденный курс и ссылка на сертификат

  Rule: Отправка email через внешние сервисы
    Система ДОЛЖНА отправлять рассылки через внешние email-сервисы (SMTP,
    SendGrid и др.).

    Scenario: Отправка письма через внешний сервис
      Given интеграция с email-сервисом настроена
      When система отправляет рассылку по группе контактов
      Then письма передаются через внешний email-сервис доставки

  Rule: Безопасный доступ к API
    Доступ к API системы ДОЛЖЕН обеспечиваться через OAuth2/JWT, а чувствительные
    данные ДОЛЖНЫ шифроваться.

    Scenario: Авторизация запроса к API
      Given клиент не имеет действительного токена
      When клиент обращается к API без токена
      Then API отклоняет запрос с ошибкой авторизации

  Rule: Хранение файлов в облачном хранилище
    Система ДОЛЖНА хранить записи звонков и сертификаты в объектном хранилище
    (S3/MinIO) и предоставлять ссылки на них.

    Scenario: Сохранение записи звонка
      Given запись разговора получена из телефонной системы
      When система помещает её в объектное хранилище
      Then карточка звонка содержит ссылку на сохранённую запись
```
