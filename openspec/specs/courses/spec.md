# Courses

Источник: PRD.md §2.3, §2.4, §2.7, §3.3 (архивирован в `docs/source/PRD.md`).
Модуль обучающих программ: каталог курсов с категориями, расчёт актуальной цены
и предложения по курсам (`CourseOffer`), а также отслеживание пройденных курсов
и сертификатов (`CompletedCourse`).

```gherkin
Feature: Courses

  Rule: Управление каталогом курсов
    Система ДОЛЖНА позволять администратору управлять курсами с названием,
    категорией (IT, Маркетинг, Менеджмент) и базовой ценой.

    Scenario: Создание курса
      Given аутентифицированный администратор
      When он создаёт курс "Python для анализа данных" с категорией "IT" и базовой ценой 50000
      Then курс "Python для анализа данных" появляется в каталоге с категорией "IT"

    Scenario: Категории курсов ограничены
      Given существует курс с категорией "IT"
      When администратор указывает курсу категорию "Маркетинг"
      Then категория курса становится "Маркетинг"

  Rule: Расчёт цены и создание предложения курса
    Система ДОЛЖНА рассчитывать цену с учётом скидки и создавать актуальное
    предложение курса (`CourseOffer`) для организации на указанную дату.

    Scenario: Создание предложения курса с учётом скидки
      Given для организации "ООО Ромашка" выбран курс "Python для анализа данных" с базовой ценой 50000
      When система рассчитывает цену с учётом скидки 20%
      Then создаётся предложение курса с ценой 40000 и датой актуальности

    Scenario: Предложение привязано к организации и курсу
      Given существует курс "Python для анализа данных"
      When система создаёт предложение для организации "ООО Ромашка"
      Then предложение связано с организацией "ООО Ромашка" и курсом "Python для анализа данных"

  Rule: Отслеживание пройденных курсов и сертификатов
    Система ДОЛЖНА хранить сведения о пройденных организацией курсах, включая
    дату окончания и ссылку на сертификат.

    Scenario: Фиксация пройденного курса
      Given организация "ООО Ромашка" завершила курс "Python для анализа данных"
      When система сохраняет запись о завершении с датой и ссылкой на сертификат
      Then в профиле организации "ООО Ромашка" отображается пройденный курс и его сертификат
```
